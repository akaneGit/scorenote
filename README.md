# ドレミふり / ScoreNote

PDF楽譜の音符を読み取り、固定ド（C＝ド、♯・♭付き）を追加するローカルツールです。ChromeまたはEdgeで使えます。

[ドレミふりを開く](https://akanegit.github.io/scorenote/)だけで使えます。オフラインで使う場合は、[最新版のダウンロード](https://github.com/akaneGit/scorenote/releases/latest)から `ScoreNote.html` を保存して開いてください。

1. 利用する権利・許諾、または適用される法定の例外があるPDFを選びます。
2. 五線・音部記号・調号・音符を自動判定し、音名を配置します。
3. プレビューを確認して「PDFを保存」を押します。

手動で五線を指定したり、音符をクリックしたりする操作はありません。判定できないページがあれば文書全体をエラーにし、保存を無効にします。配置できない場合も通常は保存できません。「音名の重なりを許可する」をオンにすると、重なりがあっても表示・保存できます。読み取り自体に失敗した場合は保存できません。文字サイズ・色・オクターブ表示・対象の段を選べます。

## 対応範囲と限界

音楽記号情報が残ったPDFが対象です。Kousaku、Emmentaler形式で検証済みで、主要なSMuFL記号の判定も実装しています。スキャン画像、記号が輪郭だけのPDF、回転ページ、暗号化PDFは対象外です。50MB・50ページまで扱います。

途中の転調、特殊な調号、交差声部、タイによる小節をまたぐ臨時記号の継続などは未対応です。装飾記号を演奏上の音列に展開しません。移調楽器も記譜音の固定ドです。

エラー検出は全ての誤認識を見抜く保証ではありません。出力前に原譜と照合してください。文字サイズを大きくして配置エラーになった場合は、小さくすると再配置できます。

## 著作権とプライバシー

[著作権について](COPYRIGHT.md)を確認してください。ソフトウェアの配布許諾と楽譜の権利は別です。楽譜のサンプル、利用者の入力・出力PDF、元PDF入り編集JSONは配布しません。アプリは楽譜を外部送信せず、ブラウザー内で処理します。解析・広告・自動アップロードはありません。PDFには音名を追記し、元の著作権表示を削除する機能はありません。

入力したPDFは作業中のメモリーで扱います。保存ボタンで出力したファイルはダウンロード先に残ります。ブラウザーやOS、利用者が別途使う同期サービスの動作までは制御しません。

## 開発

Node.js 22.13以降を使用します。

```sh
npm ci
npm run build
npm test
npm run test:browser
```

ブラウザーテストにはChromeが必要です。標準位置にない場合はCHROME_PATHで実行ファイルを指定してください。任意のローカルPDFを追加検証するときは、`npm run test:browser -- path/to/score.pdf`を使用できます。PDFはリポジトリに追加しないでください。

ビルド後のHTMLは通信なしで使えます。開発用npmパッケージの取得には通信が必要です。依存ライブラリーとフォントの条件は[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。
